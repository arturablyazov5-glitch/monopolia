# Проверка адаптива

Из корня проекта:

```sh
node scripts/responsive-check.mjs
node scripts/responsive-check.mjs http://127.0.0.1:4321 --out /private/tmp/claude-501/my-responsive-report
```

Скрипт проверяет `/`, `/sell/` и `/buy/` в системном Chrome на ширинах 360, 390, 768, 1024, 1199 и 1440 px (высота вьюпорта 900 px). Он не меняет `package.json`: при первом запуске сам ставит `puppeteer-core` в `/private/tmp/claude-501/tools`, затем переиспользует этот временный кэш. Нужен запущенный сайт; по умолчанию это `http://127.0.0.1:4321`.

В `--out` (по умолчанию `/private/tmp/claude-501/responsive-check/<дата-время>`) будут `report.json`, `report.md`, верхние скриншоты `*-top.png` и полные `*.png`. Если страница выше 17 000 px, вместо одного слишком высокого PNG создаётся серия `*-part-*.png`: каждый вертикальный фрагмент не выше 16 000 px.

Код завершения `1` означает горизонтальную прокрутку на ширинах 360–1199 px, битые видимые изображения либо ошибку запуска/загрузки страницы. Ошибки консоли и HTTP/сетевые ошибки включаются в отчёт, но сами по себе не меняют код завершения.
