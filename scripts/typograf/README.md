# Типограф «Монополии»

`rules.cjs` — дословная копия чистого блока `'use strict' … // RULES:END`
из `/Users/rafael/Documents/trace-logos/tools/figma-plugins/typograf/code.js`,
снятая 9 октября 2026. Совпадает также с `_shared/typograf-rules.js`.
Логика, регулярные выражения и DEFAULT_OPTS не изменены. Расширение не
использовано: его порт отстаёт от эталонного плагина.

`node scripts/typograf/test-parity.cjs` сверяет копию побайтно и запускает
интеграционные случаи оригинала с подменой только строкового движка на копию.
Для этого read-only теста требуется исходный trace-logos на указанном пути;
рабочий `apply-typography.mjs` автономен от другого проекта.

`node scripts/apply-typography.mjs --dry-run` показывает изменения по файлам,
`--write` применяет их. Новых зависимостей нет: используется установленный
парсер Astro. AST определяет текстовые узлы и диапазоны литералов, исходник
не сериализуется и не форматируется целиком. Чтение, разбор, правки и запись
каждого файла синхронны; перед записью проверяется, что файл не изменился.
После записи проверьте `--dry-run` (должно быть 0).

Обрабатываются тексты Astro, TS, MJS и JSON, включая `src/data/site-texts.mjs`
и строковые варианты квизов. Пробелы на границах фрагментов сохраняются,
чтобы текст перед `<strong>` или ссылкой не склеивался. Идентификаторы,
URL, CSS и служебные поля не типографируются. Копия правил не подключается
к клиентскому коду: исправленные символы записываются в исходники и сразу
попадают в HTML при рендеринге Astro.

`figma-exceptions.json` — локальные защиты переносов Figma и строк, которые
одновременно являются идентификаторами заявок. `original` — точный исходный
фрагмент, `output` — согласованный результат; без `output` исходник полностью
защищён. Правила движка не меняются. После изменения защищённого текста
исключение нужно повторно сверить с браузером и макетом.

Подробный аудит: `design-reference/typograf-audit.md`.
