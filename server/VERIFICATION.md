и срочной продаже — передаётся «Не указано», разметка не расширена.

## Воспроизведение

`node scripts/task042-core-check.mjs` — автономные серверные проверки с mock fetch.
При dev на 4321 и прокси на 8787:
`node scripts/task042-browser-check.mjs real` — повторная реальная доставка;
использовать только разрешённый личный тестовый chat. Остальные режимы:
`invalid`, `honeypot`, `dry` (прокси с LEAD_DRY_RUN=1), `network` (прокси выключен).
Между пакетами перезапускать прокси: 15 POST/IP/10 минут.
`node scripts/task042-context-check.mjs` требует production preview на 4397
со сборкой без PUBLIC_LEAD_ENDPOINT. Chrome может требовать запуск вне sandbox.
`node scripts/check-baseline.mjs` проверяет уже работающий dev-сервер.

## Осталось для эксплуатации

Нужны выбранный сервер, HTTPS-домен обработчика, разрешённый origin GitHub Pages
и PUBLIC_LEAD_ENDPOINT при сборке. VPS/Docker/Yandex инструкции подготовлены,
но реальный деплой, nginx/systemd/pm2/Docker на хостинге не выполнялись.
В памяти rate-limit сбрасывается при рестарте; для нескольких экземпляров и
Yandex нужен внешний лимит. Telegram sendMessage не даёт идемпотентности,
поэтому сетевые повторы могут доставить дубликаты (описано в README).
workers/ удалён после переноса всей полезной логики; design-reference, .env,
PROGRESS.md, agent.md, PROJECT_MEMORY.md сохранены. Коммитов/пуша/публикации нет.
