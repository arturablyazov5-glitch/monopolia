# Память проекта «Монополия»

## Решение от 5 октября 2026

Сайт верстается собственным кодом по дизайну в Figma.

### Требования

- Три продающие страницы: главная и две внутренние.
- Основная цель — заявка через форму.
- Приоритет — скорость загрузки; SEO не является приоритетом.
- На одной внутренней странице — небольшой информационный каталог товаров.
- Покупки, корзины и оплаты нет. У товара есть кнопка «Оставить заявку».
- Для каталога нужна админка.
- Хостинг — Vercel или аналогичный сервис.

### Выбранное направление

- Astro + TypeScript + обычный CSS для сайта.
- Собственные компоненты по Figma; JavaScript только для нужной интерактивности.
- Статическая генерация страниц для быстрой отдачи готового HTML.
- Sanity Studio для управления каталогом; предполагаемый адрес админки — `/admin`.
- Vercel для размещения сайта и серверного обработчика формы.
- После публикации изменений каталога — автоматическая пересборка сайта. Изменения появляются после завершения сборки.

### Каталог и заявки

Предполагаемые поля товара: название, фотографии, описание, характеристики, порядок отображения и видимость. Выбранный товар автоматически передаётся в форму заявки.

Серверный обработчик проверяет форму, сохраняет заявку и отправляет уведомление. Канал уведомлений (почта, Telegram или CRM) и место хранения заявок ещё не выбраны. Секретные ключи должны оставаться на сервере.

Собственная админка пока не требуется: используем готовую CMS, если не появятся особые требования к интерфейсу или процессам.

### Скорость загрузки

Оптимизировать изображения, шрифты, видео и сторонние скрипты; особое внимание — первому экрану. Не подключать лишние библиотеки для простой интерактивности.

### Ограничения

- Не пушить без разрешения пользователя.
- Это зафиксированное направление, реализация и подключение сервисов ещё не выполнены.
