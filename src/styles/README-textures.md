Как заменить текстуру бежевых плашек: замените файл
`public/assets/textures/paper-beige.webp` (тем же именем) — изменится везде.
URL и параметры фона заданы в `tokens.css`, общее правило — в `global.css` (TASK-044).
Изображение применяется без наложений и обработки; `cover` сохраняет пропорции, без повторов и швов.
Для GitHub Pages URL получает base через существующий `scripts/prepare-pages.mjs`, как brush-mask.
Белый бумажный контейнер получает модификатор `paper-white` (токен `--color-paper`):
он сохраняет рваный край и тень; вложенные бежевые плашки используют текстуру независимо.
