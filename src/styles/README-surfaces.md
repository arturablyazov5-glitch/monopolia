# Общие поверхности и мобильные правила

- `Paper.astro` рисует бумагу, `TapeLayer.astro` — отдельный внешний слой скотча. Маски накладываются на фоновые псевдоэлементы; контейнер, содержимое и скотч не маскируются. Для вложенного контента без второго листа используйте `surface="none"` (например, `HeroQuizCard` в `LeadDialog`).
- `brush-stroke.css` владеет масками поверхностей, `tokens.css` — общей глубиной бумажного края (`--paper-mask-sizes`). Компактные плашки без полноценной карточки используют `.paper-label` из `paper-label.css`; заливка меняется через `--label-fill`.
- `TapedNote` передаёт угол через `--note-rotate`. Позиционирование экземпляра может добавлять собственный translate без переписывания поворота и без `!important`.
- `tape.css` владеет геометрией скотча. При ограниченном окне карусели оставляйте место под выступы; не скрывайте их маской карточки. Иллюстрации с запечённым декором масштабируются целой композицией.
- `consent.css` — единственный вид чекбокса согласия. Общие тексты ошибок находятся в `lib/form-errors.ts`, общий цвет — в `.form-error` в `global.css`; локальные стили формы задают только расположение.
- `DealSteps` обновляет число, `aria-valuenow` и `scaleX` заполнения одним вычислением для всех страниц и разрешений. Не добавляйте отдельные версии прогресса в стили покупки/продажи.
- Мобильные правила общих секций живут в файле компонента (`office-consultation.css`, `deal-insurance.css`, `deal-steps.css`, `relocation-map.css`). Файлы страниц содержат отличия страниц, а не копии общих правил.
- Для стандартных внешних интервалов используйте `--section-space` (120/80/56 px). `--section-space-compact` и `--section-space-mobile` предназначены для намеренно более плотных композиций; координаты иллюстраций этими токенами не заменяются.
- Направления Telegram задаются в `data/social-links.ts`: `Telegram` — канал, `TelegramContact` — связь в формах, `TelegramJobs` — вакансии. У `SocialLinks` назначение выбирается через `purpose`.
